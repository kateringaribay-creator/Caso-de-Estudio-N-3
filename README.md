# Caso-de-Estudio-N-3
# 📊 Insurance Company EDA - Streamlit App

## 📌 Descripción del proyecto
Este proyecto es una aplicación interactiva desarrollada con **Streamlit** para realizar un **Análisis Exploratorio de Datos (EDA)** del dataset de una compañía de seguros (`InsuranceCompany.csv`).

El objetivo principal no es construir modelos predictivos, sino comprender el comportamiento de los datos, identificar patrones relevantes y generar insights útiles para la toma de decisiones.
